# Open Embodied SimOps v0.1.0-alpha.1

First public source release of a self-hosted robotics workflow workbench.
Original code is Apache-2.0. Chinese is the default UI and README language;
English documentation and UI are included.

## Included

- Task configuration, local command orchestration, logs and artifact provenance.
- Separate scene/asset, simulation, dataset, training and deployment web pages.
- ManiSkill/LeRobot integration code, dataset utilities and rollout interface export.
- Optional MotrixSim adapter; installed runtime and asset licensing is unverified.
- Core tests, CI, contribution guidance and explicit trusted-local security boundaries.
- Rebuildable 64-second bilingual project-introduction video, not simulator footage.

## Validation

Local clean Python 3.11 environment: 35 core tests passed. Source/wheel build
verified. Local dependency audit found no known vulnerabilities after upgrading
pip/setuptools; this project itself was skipped because it is not on PyPI.
Tests contain doubles; none of these checks constitutes GPU or robot acceptance.

Hosted Python 3.10 and 3.11 checks passed on commit `fbdab43`:
https://github.com/eust-w/open-embodied-simops/actions/runs/40764189932

Video assets: landscape 1920×1080 and portrait 1080×1920, 64 seconds, bilingual
on-screen copy. Actual local UI screenshots and original diagrams; original
synthesized tone track, no narration. They are project introductions, not
simulation execution demos. See the attached manifest for content hashes.

The historical GPU host was unreachable during preparation. Runtime changes
were not deployed there, and June records were not revalidated.

## Important Limitations

No built-in API authentication. Do not expose the service publicly. Native
MotrixSim viewer and interactive sessions do not yet share simulation state.
The pipeline lock does not cover all GPU consumers. Catalog integrations and
generation capabilities vary. Physical-robot deployment is unverified.

See README, SECURITY.md and THIRD_PARTY_NOTICES.md before running. The Alpha
release shares development work; it does not claim a production-ready platform.
